# Joga Bonito

Gestione calcetto: giocatori, intesa, Matchmaker, report partite e statistiche.

## Setup
1. Crea un NUOVO progetto Supabase e lancia `supabase-schema.sql` nel SQL Editor.
2. `cp .env.example .env` e inserisci `SUPABASE_URL` e `SUPABASE_SERVICE_KEY` del nuovo progetto.
3. `npm install && npm start` (http://localhost:3000).

Deploy: Render (vedi `render.yaml`), impostando le stesse variabili d'ambiente nel dashboard.
